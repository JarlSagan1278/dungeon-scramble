# Arcanist + a passive +1 to every Boost (Oct 16, build 1.41.47)

**Jeremy's question:** "What happens if the Arcanist also gets a passive +1 to all Boosts?" In this test, every Boost face the Arcanist plays counts one higher: x2 becomes x3, x3 becomes x4, and so on.

## In short
- **Today's Arcanist is now one of the two weakest classes for skilled players at depth.** Under the new X-to-X rule it wins 34% at depth 7, about the same as the Dungeoneer (36%). Armsmaster wins 57% and Guard wins 66%.
- **+1 to all Boosts lifts it to 49%.** That gives back exactly what the rule change took away: the old "into or out of the X" rule also wins 48%. It still sits below Armsmaster and Guard.
- **For regular players with no depth, +1 makes it the strongest class (79%).** Today it is mid-pack there (68%, tied with Armsmaster). That is 3 points above the Dungeoneer (76%) and 9 above Guard (70%). The old rule did the same (79%).
- **A lighter version, "+1 only on Boost dice sitting on the X", gets about half the gain.** It reaches 45% for experts at depth 7 and 75% for regular players with no depth.
- **Nothing here makes any enemy stronger.** This is a player-side buff. Jeremy's balance rule says an over-strong player piece is acceptable. The worst case is a class that is a bit easy for regular players, which is the same place the Dungeoneer already sits.

## What it means
- **The +1 is worth a lot, given how few Boost faces there are.** At the start the only Boost face is the one on the origin die. More arrive later on Maneuver Die III and on loot dice. Going from x2 to x3 makes the Boosted die 50% stronger, and a Boost usually lands on a Combo or a big Hit. That is enough to move about 15 win points for skilled players.
- **Where it helps:** fewer deaths on Floors 1 and 2 for skilled players at depth (from 25% and 31% down to 20% and 23%), and less health lost per fight on Floor 3 (7.2 down to 5.8).
- **Origins:** Halfling and Pixie gain the most (expert, depth 7: +18 and +19 points). Gnome gains the least (+7). With +1, the four origins range from 40% to 54%.
- **The "X only" version is weaker and harder to read.** A Boost die only gets the bonus when the roll lands it on one of the 8 X squares, so it gains about half as much. It also adds one more thing to check while building a path.
- **Comparing with older studies:** the game has changed since the Oct 12 and Oct 14 studies (other classes, loot dice, bosses). Read only the rows above against each other, not against those older numbers. For example, Guard at expert depth 7 was 50% on Oct 14 and is 66% here.

## Method
- **Build:** a copy of 1.41.47 built from the working tree on Oct 16 and saved as a scratch snapshot, so that rebuilds of dist/ could not change it mid-study. The tree also held another session's uncommitted edits to render.js and styles.css. Those only change the screen, which the bot never draws, so they do not affect the results. The snapshot was deleted afterwards.
- **Bot and profiles:** the same as the Oct 14 class re-baseline (`bg_oct14.py`), using `study_maneuver.js`.
  - Expert = skill 1500. It always uses its class ability, Swap/Reroll and tokens, and picks the best loot.
  - Regular = the calibrated Oct 13 profile: skill 60, ability used 35% of the time, tray actions and tokens 30%, random loot pick 60%.
- **Depth 7** = Tougher Scuffs 1, Zeal 1, Rationing Rations 1, Swarming 1, the same loadout as Oct 14. Depth 0 = no modifiers.
- **Origins:** every class row averages all four origins equally, 300 runs each, so 1,200 runs per row. Every cell used the same method.
- **How the +1 was patched:** in the test page only, not in the game's code. The game reads every face it plays through one lookup function (`pathFaceForIdx`). That lookup feeds both the real damage math and the bot's path scoring. The test wraps it so that, when the class is the Arcanist, a Boost face's multiplier comes back one higher.
  - "X only" adds one condition: the die must sit in the Arcanist's zone.
  - One-use Boost tokens from shrines are not changed.
  - The bot still values Boost dice at their printed number when it picks loot, so loot choices may undersell the bonus a little.
- **Old rule:** the Arcanist's `diagonalZone` was set to `'either'` through the study's existing `classPatch` knob.
- **Tools:** `tools/balance/study_arcboost.js` (`study_maneuver.js` plus the `arcBoost` knob: `none`, `all` or `zone`) and `tools/balance/bg_arcboost.py` (the cell driver). Raw results are in `out_arcb_*.json`, which git ignores.

## Recommendation
- **Ship the +1 to all Boosts if Jeremy wants the Arcanist back in the pack for skilled players.** It fully undoes the cost of the X-to-X rule (49%, against 48% with the old rule) and keeps the new, cleaner movement rule.
- **The trade-off:** for regular players it becomes the easiest class (79%, about 3 points above the Dungeoneer). That is a player piece being strong, which the balance philosophy accepts, and no enemy gets harder.
- **If that feels like too much for new and regular players,** "+1 only on Boost dice on the X" is the middle option (45% expert at depth 7, 75% regular). It is fiddlier to explain, though.
- **Leaving the Arcanist as it is** means it shares last place with the Dungeoneer for skilled players at depth (34–36%). For regular players it stays mid-pack (68%).
