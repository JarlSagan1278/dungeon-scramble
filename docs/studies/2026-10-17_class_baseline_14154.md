# Class baseline on build 1.41.54 (Oct 17)

**Why:** both class passives from Oct 16 are now in the game: the Arcanist's +1 to every Boost and the Dungeoneer's "+1 damage after a wrap". This study gives a fresh reference table for all four classes, so future studies can compare against today's numbers. Nothing was patched or changed for the test. The bots played the game as it is.

## In short
- **The Oct 16 predictions held.** All eight predicted numbers landed within the margin. The biggest gap was 3 points.
- **Skilled players at depth 7 (the hard setting):** Guard 63%, Armsmaster 57%, Dungeoneer 55%, Arcanist 50%. The four classes are now 13 points apart. Before the two passives they were about 30 points apart (Guard 66% vs Arcanist 34% / Dungeoneer 36%).
- **Regular players at depth 0 (no modifiers):** Dungeoneer 83%, Arcanist 79%, Guard 70%, Armsmaster 68%. The two classes that got passives are now the easiest for regular players, as the Oct 16 studies warned. That is a player piece being strong, which the balance rule allows.
- **Where the classes die is different.** At depth 7, the Arcanist dies early: 36% of its deaths are on Floor 1. Guard and Armsmaster rarely die on Floor 1 (12%). Their losses come on Floors 2 and 3.
- **Gnome is the weakest origin for skilled players at depth with every class.** It is 8 to 18 points below the best origin. Halfling or Pixie is the best origin for every class.
- **One caveat:** this build still had the Boost-token bug (fixed in 1.41.56; see "Build note" below). It affects every study since Sep 30 in the same way, so these numbers compare fairly with the Oct 16 ones. They likely run a little low for today's build, most for classes and origins that use Boost.

## How to read the tables
- **Win** = share of runs that beat the Floor 3 boss. The **±** is the 95% margin: the true rate is very likely within that range. Two classes whose ranges overlap may really be tied.
- **Floor** = the average floor a run ended on. 3.00 means every run reached Floor 3.
- **HP lost per fight** = the average health lost in each fight the player won.
- **Died on F1 / F2 / F3** = share of *all runs* that ended on that floor. Win plus these three adds up to 100%.
- **Share of deaths** = the same deaths, split so they add up to 100%. It shows *where* a class tends to lose.
- Each row is **1,200 runs**: 300 each for Dwarf, Gnome, Halfling and Pixie. No run timed out.

- Every difference is within the margin. The passives built into the game play the same as the test patches did.

- Expert depth 0 matches the Oct 16 tables within 1 point for every class.

## Build note: the Boost-token bug
- The runs used build 1.41.54. Build 1.41.56 (released while this study ran) fixed a bug where shrine **Boost tokens** were used up but did nothing. The bug dates back to Sep 30. Every study since then, including both Oct 16 studies, had it too, so this table compares fairly with them.
- On 1.41.56 the expert bot (which always uses its tokens) should do slightly better. Regular players use tokens only 30% of the time, so they gain less. The size of the change is not measured here. A short rerun of the expert depth 7 row on 1.41.56 would show it.
- 1.41.56 also stopped the FTLeporter relic's teleport from counting as a Dungeoneer wrap. That only matters in runs where the Dungeoneer holds that relic, so its effect here is very small.

## Method
- **Build:** 1.41.54 (clean tree at commit 6fb3305), built with `node build.js` and copied right away to a scratch snapshot (`tools/balance/_base14154_build.html`). The runs used it through `DS_HTML`, so later rebuilds of dist/ could not change it. All 64 cells finished on that snapshot before a container restart, so nothing was rerun. The snapshot was deleted afterwards.
- **No knobs:** the Arcanist's `boostPlus:1` and the Dungeoneer's `seamDamage:1` are part of the game data. The runs used `study_maneuver.js` directly (`study_arcboost.js` / `study_dngpassive.js` with no knob set are the same script).
- **Bot and profiles:** the same as both Oct 16 studies.
  - Expert = skill 1500. It always uses its class ability, Swap/Reroll and tokens, and picks the best loot.
  - Regular = the calibrated Oct 13 profile: skill 60, ability used 35% of the time, tray actions and tokens 30%, random loot pick 60%.
- **Depth 7** (internal; shown as depth 6) = Tougher Scuffs 1, Zeal 1, Rationing Rations 1, Swarming 1. Depth 0 = no modifiers.
- **Origins:** every row averages all four origins equally, 300 runs each, so 1,200 runs per row and 19,200 runs in all.
- **Margins:** 95% margin = 1.96 × √(p(1−p)/n).
- **Tools:** `tools/balance/bg_base14154.py` (the cell driver; it skips finished cells, so it can resume) and `tools/balance/agg_base14154.py` (the tables, including the share-of-deaths split). Raw results are in `tools/balance/out_base14154_*.json`, which git ignores.
- **To compare a future change against this baseline:** run the same profile and depth on a new snapshot with `bg_base14154.py` (change the label prefix and snapshot name), and compare only rows that use this method.
