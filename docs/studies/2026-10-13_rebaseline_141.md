# Re-baseline on 1.41.0 (Oct 13, 2026)

Build 1.41.0 (harder Floor 3, Extruzeon Layer by Layer, Swarming cap, Maneuver II/III Block ladder). 16 origin x class pairs x 200 runs per profile. Bots: expert (player-like, skill 1500), regular and new (see 2026-10-13_overnight.md section 8). Depth 7 loadout: Tougher Scuffs 1, Zeal 1, Rationing 1, Swarming 1.

## Win rate
| Profile | 1.39.7 | 1.41.0 | Class wins (Armsmaster / Guard / Dungeoneer / Arcanist) |
|---|---|---|---|
| Expert, Depth 0 | 97% | 96% | 97 / 99 / 94 / 95 |
| Expert, Depth 7 | 46% | 43% | 49 / 54 / 31 / 37 |
| Regular, Depth 0 | 77% | 73% | 66 / 70 / 76 / 77 |
| New, Depth 0 | 59% | 51% | 41 / 42 / 60 / 61 |

The Maneuver Block ladder gave back about 8 of the ~12 points the harder Floor 3 took (regular: 65% with Floor 3 alone, 73% now).
