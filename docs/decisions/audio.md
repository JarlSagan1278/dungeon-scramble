# Audio

Music direction and pieces, tempos, sound effects. Jeremy's decisions, oldest first, with dates and the build they shipped in. Split out of PROJECT_CONTEXT.md on Oct 28, 2026; add new decisions at the bottom.

- Sound effect pass: audit which actions make sound and any redundancy; one consistent theme; a rising-note melody tied to musical tension and success; dice materials change roll sound and quantity; stronger enemy-turn and shrine sounds; airier Maneuver/dodge sounds.
- Background music: heavy klezmer harmonic-minor battle music, success/loot music, different orchestration per floor, MIDI instruments via GarageBand.
- **Music direction (Jeremy, Oct 12):** toy-like, over a lonely, driving bass line in the spirit of the **Zelda II Palace theme** (a relentless ostinato; inspiration, not a copy). Lead melody in **harmonic minor**, klezmer flavored: sad and hopeless in downtime, frantic and stressful in action. Pieces: uptime and downtime for each floor (slightly different orchestrations), victory, treasure, camp, shrine. Jeremy composes in GarageBand with MIDI; Claude can supply a music spec, MIDI sketches, klezmer vocabulary (freygish, doina, freylekhs/bulgar 3+3+2, krekhts ornaments), integration advice (uptime/downtime as crossfadable layers with the same tempo, key and loop length; .m4a loops; size budget; ducking under SFX), and can retune the major-pentatonic SFX ladder to each floor's key. Nothing built yet.
- **SFX key (Jeremy, Oct 13):** sound effects use the music's scale ("harmonic minor phrygian" = A freygish / D harmonic minor): `sfxInKey()` snaps every pitched tone to the scale and ladders climb scale tones from A; percussion/metal tones keep their pitch (`SFX_FREE_PITCH`). If a floor's music changes key later, change `SFX_KEY_PCS`.
- **Music approach (Jeremy, Oct 13):** in-game synth from note data (src/music.js, `MUSIC_TRACKS`), not audio files -- he likes the preview instruments. Downtime sketch voices: triangle bass + toy accordion (his pick over clarinet). Arrangement = 8-bar blocks [bass], [bass], [bass + melody], [bass + melody], cycling (Jeremy, Oct 13); melody level lowered (LEAD_LEVEL 0.09); melody notes never overlap. For now it plays through the whole run; per-screen choice (downtime vs action layers) comes with the action sketch. Stems from GarageBand stay an option (~100-120 KB per 8-bar stem).
- **Action music rule (Jeremy, Oct 13):** downtime everywhere in a run; live Boss / Elite / Deadly fights switch to the action version (melody all the time, accordion); boss phase 2 adds the drums; switches happen on bar lines. Easy and Standard fights stay on downtime. Later ideas offered: tension triggers inside any fight (heavy-turn telegraph, low HP).
- **Music round 2 (Jeremy, Oct 13):** Floors 2-3 = the same tune transposed (E/150, F/160; tempos lowered to 145/150 on Oct 13) with added layers (MUSIC_FLOORS in music.js); the victory chime replaces the old fight-won ding (bar-synced, 3 variants); loot burst chord per tier; camp lullaby (3/4, 84 bpm). SFX key follows the floor (sfxShift). Next per the spec: run-victory piece, shrine music.
- **Music round 3 (Jeremy, Oct 13):** shrine piece (A freygish, 96 bpm, drone + glass) and a 32-bar title/end theme (title, setup, win and loss screens). One combined preview page for all music, built from the game's own engine: docs/music/game_music.html.
- **Music (Jeremy, Oct 13, later):** the downtime -> action switch was jarring: added a cheap 2-beat fill (snare roll + bass walk-up + crash). Long title/end theme order: downtime bass, downtime bass, downtime full, downtime full (transition beat), action no drums, action + countermelody no drums, action full, action full, action bass, action bass, repeat (8 bars each; "full" = bass + melody + drums + countermelody, Claude's reading).
- **Floor tempos (Jeremy, Oct 13):** the bpm rise ended too high; Claude picked smaller steps (140 / 145 / 150, Floor 1 unchanged) over lowering everything; easy to switch to e.g. 125/135/145.
- **End-of-run stings (Jeremy asked, Oct 13, 1.41.4):** run-win freylekhs landing on D major and a run-lost doina ending on D minor (STINGS / musicSting in music.js); the title theme resumes after. With these, every piece in the music spec is in the game (treasure is still a per-tier chord rather than the spec's rising arpeggio).
- **Tempo (Jeremy, Oct 14, 1.41.5):** music starts at 130 bpm on Floor 1, +5 per floor (130/135/140). Title theme and stings follow Floor 1's tempo (Claude's call, so they match the run's opening).
